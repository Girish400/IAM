# Exam and score records

The practice exam is hosted at [girish400.github.io/IAM](https://girish400.github.io/IAM/) and its source is in [`../website/`](../website/). A completed attempt is saved in the taker's browser on that device. The results screen also provides a CSV download that can be placed in this folder when a repository copy is wanted.

GitHub Pages serves static files and cannot write a visitor's results into this repository. No names, email addresses, or other personal details are collected.

`score-log.csv` is an optional local log template. It is not populated automatically by the public website.
